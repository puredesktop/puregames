# Contributing to PureGames

Anyone may report a bug, propose an improvement or open a pull request at
[puredesktop/puregames](https://github.com/puredesktop/puregames).

1. Open an issue before a substantial change, or send a focused pull request.
2. Fork the repository and make changes on a branch in your fork.
3. Follow the setup instructions in the README. Run `npm test` and, in a
   compatible PureDesktop workspace, `npm run build`. Describe what changed,
   why, and how you checked it.
4. Preserve copyright and licence notices. Identify any new dependency and
   its licence. Do not include credentials, private data, or game assets you
   do not have permission to distribute.

Contributions to original app code are provided under the MIT licence.
Third-party components retain their own licences.

Community contributions come through issues and pull requests. Only repository
and organisation administrators may merge or update the protected main branch.
Please do not request direct write access to contribute.
